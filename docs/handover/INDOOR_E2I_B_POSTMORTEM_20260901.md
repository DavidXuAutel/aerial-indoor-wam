## 2. 原因分析（机制）

### 2.1 A 为什么涨：视觉域差被补了一刀

室外 WM encode 看室内中庭/家具会偏。A 用室内 RGB 短窗 warm-start encode，再训 π → @0.50 从崩到稳。  
**证伪**：「再堆同款 C1 碰运气」；**证实**：encode 域适配有效。

### 2.2 @0.20 为什么仍挂：容错被砍 + 双失败模式

大厅空旷是天花板尺度；机头前方是花槽/椅腿/立柱/展柜。π 偏前向追 goal，侧绕弱。  
0.5→0.2 后，「擦边到」变「差几十厘米就撞」。

C2 拆分（24 段）：**SPAWN 10 / NEAR_COLL 8 / ARRIVE 5 / MISS 1**。  
R01（第一条短路由）三次全 SPAWN——不是「飞不好」，是出生点污染。

### 2.3 B 为什么没涨反跌（假设 → 证据状态）

| 假设 | 状态 | 说明 |
|------|------|------|
| H1 训练滤掉 SPAWN 路由，评测仍含坏起点 | **待视频确认** | 续采跳过 R01；评测 8 路由全开 → 开场撞白学近场 |
| H2 只模仿「已很近且无撞」，不会绕障/脱困 | **待视频确认** | B @0.20 近场撞仍多 |
| H3 以 0.2 为目标再 FT 冲掉 A 的中段稳定 | **S3 证伪「B 损中段」** | @0.50 回测 B mean **更好**（1.54 vs A 1.91）；@0.20 仍崩 |
| H4 「有一次到点」规则曾掩盖质量 | ✅ 已证实 | C2 脆过；B 质量门诚实 FAIL |
