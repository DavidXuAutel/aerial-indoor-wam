## 0. 一句话

室内方案最致命的，不是「场景难」，而是：**用特权夹具 + GT 位姿 +（曾）全接管罩，在测一个从未按合同训练的室外大脑能否 0.2 m 到点**——训练与验收合同自相矛盾，结构上接近不可证。

E2i 的 dt/罩修复与 B1 解禁**正面打「安全层锁死」**，但不自动消解「夹具主料 / gt_proxy 合同」两条致命残留。

## 1. 致命缺陷（会把方案做成假闭环）

### F1 — 大脑合同自相矛盾（最大头）

| 写的是 | 实际做的 |
|--------|----------|
| WAM π 是唯一飞行核 | 能进圈的正例几乎全靠 **GT-PD / `gt_pd_body` 夹具** |
| 夹具仅对照 / BC 辅料 | E2h～E2i 的 FT 主料长期是夹具；B1（`assist=none`）曾被罩挡住开不了 |
| 验收 `assist=none` | 训的是「看夹具飞」的动作分布 |

**为何致命**：夹具能到 ⇒ 动力学可达；WAM 到不了 ⇒ 学的不是自己会飞的分布。  
再堆 B2（已有 34 条 @0.20 夹具）仍可能学不会，因为评测时夹具被关掉。

**解法约束**：若不把 **`assist=none` + 新罩下的近成功** 做成主料，室内主航道在结构上过不了门。  
**当前缓解**：E2i.1 过门后 B1 已解禁（见 STATUS）；B2 在 FT 混合中须 **≤30%**。

---

### F2 — `gt_proxy` 当默认，产品合同从未真正测过

主航道写的是：`RGB + IMU + 高度 → \(\hat p\) → goal_rel → π`。  
现状几乎全程：`obs.position` / `gt_proxy` 算 `goal_rel`。

**后果**：

1. 现在的 0/3 @0.20 已经是 **上帝位姿 stub 下的 FAIL**  
2. 即便哪天 stub 过门，也 **不能** 写成「室内传感合同完成」  
3. E3（真 odom/VIO）被禁是对的，但意味着：**当前整条 E2\* 都不在验收坐标系上**

**致命点**：报表容易把 stub 进展误读成产品进展。  
**纪律**：`gt_proxy` 过门只能当**中间探针**，禁止写入主航道完成态。

---

### F3 — 安全罩曾（且可能再）在「导航」，不是「安全」

已证实的工程级 bug（修前）：

```text
dt = limits[0] / MAX_V = 0.15/5 = 0.03s
→ 开阔处 max_dx≈0.022 ≪ 策略 0.15
→ intervention ≈ 0.95–1.0（永久 three_zone）
```

**连带结构问题**（不随单点 bug 消失）：

- π 指令被盖掉 → **近场不可学**  
- 语料存的是 shield 后动作，不是 `action_commanded` → **逼障带对 WM/π 是外推**（见 LIVING_DOCS 同源结论）  
- shield-off best **0.63 m 且 collided** → 不能当「π 已会近场」

**已缓解**：`_dt_from_limits = limits[0]/v_cruise`；F1/F2 post-dtfix ✅（v3 interv **0.048**≪0.5，d_end↓47.8%）。  
**仍致命的残留**：若以后再缩盒 / 换 cruise / hardcode 罩参数，同一类尺度错配可复发；完成态仍须罩 ON + 低介入 + `collided=false`。

工件：`artifacts/indoor_shield_channel_diag_v3_seed0_20260831.json`（修前）；`artifacts/indoor_shield_ab_summary_post_dtfix_20260831.json`（修后）。

### F4 — 尺度/域迁移被当成「缩盒就能搬」

| | 室外 baseline | 室内目标 |
|--|---------------|----------|
| 段长 | ~30 m | 3–6 m |
| 到达 | ~3 m | **0.2 m** |
| 视觉 | 开阔长距 | 走廊/大厅近障 |
| 动作盒 | 巡航级 | 微步长 |

4090×500 iter × 百条夹具 **不算重训**；E2d @0.50 脆过还是在 **室外域**。  
把「室外 ckpt + 缩盒 + 短 FT」写成室内方案，本质上是 **数量级任务替换却假装是同模型适配**。

**致命点**：方案默认低估域差——很可能要 **WM encode 室内适配**，而不只是 π FT。  
**解法约束**：C1 @0.50 仍不过 → 停并评估全量室内适配；禁止单路由补洞冒充重训。

---

### F5 — 「撞近」与「到点」曾可被混用（指标污染）

| 条件 | 现象 | 误读风险 |
|------|------|----------|
| 罩 OFF | 0.63 m **碰撞** | 当成「π 已会近场」 |
| 罩 ON（修前） | ~1.8 m 不撞、不进圈 | 当成「只差一点数据」 |
| 夹具 @0.50 | 能进圈 | 当成 WAM 能力 |

若过门只看 `d_end`、不强制 `collided=false` + `assist=none` + 罩 ON，就会用 **撞近 / 夹具** 刷假进度。

**已缓解**：E2i v2 过门强制 collision 不恶化；完成态禁关罩。  
**纪律**：任何 shield-off / 夹具数字 **禁止**写入完成态。

## 5. 对当前 E2i 路线的诚实判断

| 项 | 判断 |
|----|------|
| E2i 方向（dt→罩 A/B→B1 主轨→分阶 FT） | **对** — 正面打 F3 + 语料形态 |
| F3 工程 bug | **已过门缓解**（interv 0.048） |
| F1 残留 | **未解** — 取决于 B1 能否采出干净近成功；否则夹具主料复发 |
| F2 残留 | **未解** — 全程 `gt_proxy`；C2 过门≠产品完成 |
| F4 残留 | **未证** — C1 失败才升级 WM encode / 全量适配 |
| C2 @0.20 保证 | **无** |

**存活条件**（缺一则方案回到假闭环）：

1. 罩保持低介入（interv≪0.5）且完成态罩 ON  
2. **`assist=none` 近成功成为 FT 主料**（B1≥50%）  
3. 夹具 B2 ≤30%，且永不写完成态  
4. `gt_proxy` 成绩只标探针；世界系 0.x m 前须估计器消融  
5. C1 不过 → 停，评估室内 WM+π 适配规模（禁单路由补洞）
